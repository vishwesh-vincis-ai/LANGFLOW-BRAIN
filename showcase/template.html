      How it works
      
From a question to a cited answer

    

    
    
      
  1. 1Ingest. Price lists, FAQs and policies are split by heading and stored in Postgres with a full-text index and a 1024-dimension embedding. Re-sync skips unchanged files by content hash.
    2. 
      
  2. 2Retrieve. Keyword and vector search run side by side, filtered to one business, and are merged with reciprocal rank fusion.
    3. 
      
  3. 3Answer. The model sees numbered sources and must cite them. A reply with no valid citation is discarded as a guess.
    4. 
      
  4. 4Hand off. If nothing grounded comes back, or the customer asks for a person, the brain collects name and phone, remembers them for the session, and drafts an alert to the owner.
    5. 
      
  5. 5Act. Calendar tools check opening hours and free slots, then book, reschedule or cancel inside a database transaction.
