What to try

A price question gets an answer with its source. A question the documents don't cover gets a handoff: the brain asks for a name and number, then drafts an email to the owner. Asking for "a real person" does the same.

Each answer carries the section it came from. If the model's reply cites nothing valid, it is thrown away.

Why a brain, not a chatbot with your documents pasted in

Same model, same 51 customer questions, same honesty rules. The only difference is the architecture: the brain retrieves the few sections it needs and must cite one, the usual setup pastes every document into every prompt.

Connect another agent

The voice agent, the WhatsApp agent, Langflow and Claude all use the same brain. Reading and chatting are open; anything that books, cancels or changes the inbox needs the brain API key.
